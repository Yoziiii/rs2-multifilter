# RS2 过滤升级 · v0.8.0 Alpha

适配：**Minecraft 1.21.1 / NeoForge 21.1.248 / Refined Storage 2.0.9**。
原版旧 RS 1.12.4 JAR 和 Create 6.0.10 是本工程的兼容性与交互参考。

## 本版已经实现

- 四个真正的 Minecraft 菜单物品槽，位置沿用旧版 RS `GridContainerMenu` 的 x=204 / y=6+18×序号。
- 普通网格、合成网格、样板网格共享的 `AbstractGridContainerMenu` 负责自动安装四个槽。终端拉伸后自动重建。
- 每个槽保存独立的过滤卡；插拔会同步到同一终端的使用者。已安装卡随方块数据存储；普通玩家拆除方块会返还。
- 原版过滤卡物品像素和旧版四槽边框纹理；卡片可插拔，槽里的物品由 Minecraft 原生容器同步。
- 过滤分类标签显示在终端上方；「全部」+物品图标，支持分页。每张卡最多 64 个分类，四卡最多显示 256 个分类。
- 从玩家背包选择样本物品，添加所属 MOD、具体物品、物品标签。可以组合任意多个 MOD（例如农夫乐事和灾变）。
- Create 6.0 属性过滤的可选桥接：当整合包安装 Create 时，调用其实际的属性发现、序列化和 `appliesTo` 机制。用户界面保存和恢复属性时显示人类可读名称。
- 类别模式支持任意白名单、全部白名单、黑名单；也支持单独排除某条条件。
- 扩展条件：可食用、是否可损坏、实际已损坏、已附魔；以及流体 ID / 流体标签。流体样本可以从可识别的桶或流体容器读取。
- 严格物品比较：可选择按物品 ID 过滤，也可选择严格匹配附加组件数据。
- 过滤卡复制配方：已配置卡 + 空白卡 => 新卡；保留原卡。
- 恢复旧版的合成原料：石英富集铁、纸、漏斗。
- 可读取 v0.5-0.7 的 v1 格式卡片数据，并兼容 0.6 的单槽方块旧数据。

## 游戏内操作

1. 备份存档，并移除旧版本 `rs2multifilter`。
2. 将构建产物的 `rs2multifilter-0.8.0-alpha.jar` 放进 `mods`。
3. 右键手持过滤卡，建立分类，点击背包里的样本物品，再进入「选择属性/物品标签」。
4. 在任意一个分类中依次加入多个 MOD 或属性规则，保存卡片。
5. 打开普通、合成或样板终端，像旧版一样把卡片放进四个真实卡槽。顶部分页浏览分类。

## Alpha 测试范围和限制

CI 进行 Java 编译、单元测试、JAR 内容检查、NeoForge 专用服务器启动测试。
专用服务器启动成功不等于游戏客户端 GUI、实际槽位点击和所有属性都已在玩家整合包中验证。
仍需测试客户端 JEI 排版、旧版标签外观细节、非玩家破坏方块时的卡片返还、无线/便携网格的兼容性。
特殊附属模组提供的 Create 属性可能依赖它们自己的逻辑；识别或解码失败时会安全地不匹配，不会假装识别成功。
