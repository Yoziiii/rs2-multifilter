# 复活吧 我的过滤升级

英文别名：RS2 MultiFilter。

当前发行构建：**0.9.0**。英文别名及技术标识保留不变；功能实现沿用已验收 RC。

为 Refined Storage 2 终端提供可配置的物品与流体分类视图。既有测试版已经用户游戏验收，未报告异常；这不代表全部第三方组合兼容。**RC 的构建、许可证打包、265 项自动测试和隔离专服加载检查已通过；客户端额外启动检查按“依据游戏验收及包内容一致性豁免”记录，未记为客户端实测通过。** 首个正式版相对 RC 仅将包内版本从 0.9.0-rc.1 更新为 0.9.0；后续增加模组显示图标并更新显示名称，83 个 class 与既有功能保持一致。上述打包与名称调整未重跑整套测试或启动游戏。原始验收记录保留在[RC 清单](docs/RC_CHECKLIST.md)。

## 主要功能

- 每张过滤升级保存多个自定义分类，支持名称、图标、新建、切换、删除和保存；空配置打开编辑器时准备一个默认分类。
- 终端提供四个真实过滤升级槽，顶部图标选项卡显示固定“全部”与自定义分类，过多时分页。“全部”是视图，不占分类数量，也不能删除。
- 包含/排除规则、或/且/非模式、模糊物品 ID 匹配与精确组件匹配；支持模组、物品、标签、流体及部分物品属性条件。
- 可选 Create 属性候选；悬停同时显示多条，滚轮只在候选区域选择，不自动添加。普通添加和反向添加分别操作。
- 右键复制候选或已选规则：可读描述及完整内部数据，已选规则含方向；显示宽度不截断复制内容。
- 编辑器提供 36 个真实背包槽和临时 Ghost Slot；选样本不移动、不消耗真实物品，关闭后不永久保存样本。
- Shift+左键快速取回已安装卡；背包满则留原槽。保留原有复制配方。
- 终端侧边开关控制重新打开时是否记住上次分类；关闭时回“全部”。

这是终端显示视图过滤，**不是服务端物品访问权限控制**。

## 安装与使用

先备份世界及现用 JAR，每个实例只保留一份本模组。两端安装、升级、卸载和完整回滚步骤见[安装与卸载](docs/INSTALL.md)。

1. 使用上述环境安装本模组及 RS。在 RS 创造分组搜索“过滤升级”，或使用现有合成配方。
2. 主手右键打开，从背包选临时样本；选择候选，添加包含/排除规则，设置模式、图标和名称后保存。
3. 放入终端四槽之一，点击顶部分类图标，悬停看名称；“全部”保留原生搜索及全部视图。
4. 需要 Create 属性才安装兼容的 Create 及其自身依赖。JEI 配方转移还涉及 RS JEI Integration，不能只凭安装 JEI 判断“+”应可用。

## 重要修复

- **H1：**合法旧 v1 配置无损读取、同步和复制，不强制超限迁移；保存失败报错并保留原数据。
- **H3：**区分空白、有效、未知及损坏配置，阻止不可读原配置被保存/复制静默覆盖。
- **H2：**在终端真正移除时交付四卡，避免取消事件提前掉落与重复；RS 扳手保留原生打包路径。
- **H4：**属性缺失、加载或执行失败时保留原规则，暂停受影响卡全部分类并诊断；其他正常卡可用，恢复后重检原规则。
- **JEI：**临时配方/物品切屏保留仍存活菜单的分类、选择和分页；真正关闭/断连才清理。
- **M1/M2：**每菜单复用配置快照；属性/精确样本缓存限容量、LRU 淘汰，并随世界/连接/注册表/标签生命周期失效。

见[更新日志](CHANGELOG.md)及[RC 发布记录](RELEASE_NOTES.md)。本次不改变上述实现、UI、注册 ID、网络或卡片格式。

## 验证范围与限制

RC 本轮实际执行的完整自动测试为 **265 通过，0 失败、0 错误、0 跳过**，覆盖 H1—H4、JEI 生命周期和 M1/M2；已有隔离专服加载独立 RC 到 Done 并正常停服记录。用户反馈稳定测试版游戏验收未见异常。RC 与该包的 83 个 class 及现有运行资源逐字节相同，仅版本号和新增许可文档不同，因此客户端额外启动检查经用户确认豁免；此前检查由用户手动关闭，未完成，不记为 RC 客户端实测通过。

这不代替真实 Create 附属失效/恢复、所有 JEI 转移路径、多人专服竞争、磁盘重启或其他版本/整合包专项。属性自动测试使用测试实现，JEI 自动测试模拟屏幕生命周期。独立 JVM 性能数据不是游戏帧时间或 FPS 收益。见[RC 清单](docs/RC_CHECKLIST.md)。

Create 注释中的“6.0+”不是整个系列实测承诺；本机 6.0.10 已核对公开签名。不支持的 codec/超长数据可能不出现在候选中，不承诺所有附属属性可发现；已保存属性失效仍受 H4 保护，不自动删除。

物品名称有英文翻译，但编辑器、规则说明及诊断中仍有中文文本；英文发布介绍不代表已经提供完整英文界面。空规则分类显示空结果，“全部”返回原生全部视图。分类与规则数量受编码容量限制，不支持无限配置。
