# RS2 多分类过滤卡 · 0.6.0-alpha

用于 **Minecraft 1.21.1 + NeoForge 21.1.248 + Refined Storage 2.0.9**。

本仓库正在开发；首次使用请在备份存档上测试。本项目不是精致存储官方模组。

## 核心功能

- 一张卡保存最多 64 个分类；每类可以包含多个模组 ID、物品 ID、物品标签。
- 一个分类中的包含规则是 **并集（OR）**；排除规则优先。
- 过滤卡右键打开图形编辑器：点击左下方背包中的样本物品，在右侧选择加入所属模组、指定物品或一个物品标签。
- 自定义分类名称、分类图标（选择样本后点击“用样本做分类图标”）。
- 原 RS 终端界面上方增加一排小图标分类标签，不会在右侧遮挡 JEI。
- 终端左上方有一个独立卡槽：鼠标拿着过滤卡点击卡槽安装，光标为空时点击可取回。
- 卡片配置随终端所在方块保存；普通玩家挖掘终端时会尝试返还已安装卡片。
- 已配置卡与空白卡合成复制全部分类规则，并保留原卡。

## 安装和试用

1. 备份存档及整合包配置。
2. 删除旧版 rs2multifilter JAR，仅保留当前版本。
3. 将构建产物的 `rs2multifilter-0.6.0-alpha.jar` 放进 `mods`。
4. 在测试世界使用 `/give @s rs2multifilter:filter_card` 获取卡片。
5. 手持卡片右键，建立分类。先点背包里的机械动力物品加入 `create` 模组，再点附属模组物品加入其模组，两者即合并为同一分类。
6. 在终端界面用鼠标拿起卡片，点击左上方卡槽插入。点击物品图标切换分类。
7. 空手点击卡槽取回卡片。

## 验证和已知风险

GitHub Actions 负责编译、单元测试、打包检查和无界面 NeoForge 服务器启动测试。
无界面服务器启动不等于客户端 GUI 已经通过游戏内测试。请在备份存档试装，遇到异常提交 `latest.log`。

目前终端被非玩家方式破坏（例如部分模组机器或爆炸）时的卡片返还流程尚未完整覆盖；在验证前不要在正式存档里依赖这一点。
