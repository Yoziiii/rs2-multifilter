# RS2 过滤升级 v0.9 Alpha

**适用：Minecraft 1.21.1 + NeoForge 21.1.248 + Refined Storage 2.0.9。**

## 这版针对用户实测的修复

1. **过滤卡取出掉落物**：修复旧版四过滤槽位于新版 RS 主面板外时被 Minecraft 当作“点击界面外”并扔出光标物品的问题。卡槽仍然是真实的原版容器物品槽，不是普通按钮。
2. **卡片编辑界面模糊**：编辑界面取消渲染 Minecraft 的世界背景模糊，改用不透明面板，避免背景透字及过大按钮。
3. **Create 风格的单屏交互**：左侧是参考物品槽及玩家背包（可点击选择或拖到参考槽，样本不消耗）；右侧实时列出所属 MOD、物品标签、具体物品、兼容的 Create 物品属性等。每条规则直接点 `+`（包含）或 `−`（排除）加入，下面直接管理已选规则。**没有“选择属性”子页面，也没有“单独添加所属 MOD”的大按钮。**
4. **模糊物品匹配**：默认匹配注册物品 ID，不比较耐久、附魔、名称等组件数据，因此两把附魔不同的下界合金剑都属于同一分类；关闭模糊则按整个物品的组件数据严格匹配。切换时尽可能转换当前样本对应的已有物品规则。
5. 保留旧版 RS 四过滤卡槽、旧版卡片图标、分类标签及复制配方；保留任意/全部白名单和黑名单、流体与标签筛选。

## 使用方法

- 备份世界、只保留 `rs2multifilter-0.9.0-alpha.jar`。
- 手拿过滤卡右键，创建分类，然后点击左侧背包中的参考物品（也可拖向参考槽）。
- 右侧立刻显示参考物品的属性；点击 `+`/ `−` 添加包含/排除规则。
- 同一分类可把 Create、农夫乐事、灾变等任意几个模组的“所属模组”条件组合进去。
- 要筛选所有附魔/耐久不同的下界合金剑：开启“模糊”，参考槽放一把下界合金剑，选择“物品种类：下界合金剑”再按 `+`。
- 点击“保存”，在终端的真实过滤卡槽里插入卡片，终端上方出现过滤标签。
